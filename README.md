# Altyn Lead Bot

Telegram-бот для сбора и ручной обработки потенциальных B2B-лидов на франшизу Altyn.

Бот собирает публичные контакты обменников, OTC/P2P-команд и команд с крипто/финансовым трафиком, удаляет дубли, оценивает релевантность и выдаёт проекты по одному через Telegram. Проекты с Telegram-контактом показываются первыми; если Telegram не найден, бот сохраняет доступный email. Холодные сообщения бот не отправляет: менеджер проверяет проект и связывается с ним вручную.

## Возможности

- сбор публичных контактов с сайтов обменников, OTC/P2P-команд и команд с трафиком;
- поиск Telegram и email;
- обход страниц контактов, партнёрства, поддержки и социальных сетей;
- выбор лучшего Telegram для коммерческого предложения;
- оценка лида от 1 до 10 с понижением платежных gateway, gift-card сервисов и крупных инфраструктурных проектов;
- очередь горячих лидов с оценкой 8+;
- кнопка перехода в Telegram;
- отметки `Взял в работу` и `Пропустить`;
- поиск, статистика и экспорт CSV;
- автоматический сбор новых контактов по расписанию.

## Запуск

Требуется Python 3.10 или новее. Внешние библиотеки не нужны.

1. Создайте бота через `@BotFather`.
2. Задайте переменные окружения в терминале или панели хостинга.
3. Укажите `BOT_TOKEN` и при необходимости `ALLOWED_USER_IDS`.
4. Запустите:

```bash
python main.py
```

Пример для PowerShell:

```powershell
$env:BOT_TOKEN="токен от BotFather"
$env:ALLOWED_USER_IDS="ваш Telegram ID"
python .\main.py
```

## Переменные окружения

```text
BOT_TOKEN=токен от BotFather
ALLOWED_USER_IDS=ваш Telegram ID
LEADS_CSV=altyn_leads.csv
LEAD_STATE_JSON=lead_state.json
REPORT_CHAT_ID=ваш Telegram ID
AUTO_COLLECT_INTERVAL_HOURS=24
AUTO_COLLECT_LIMIT=30
```

`ALLOWED_USER_IDS` ограничивает доступ к боту. Несколько ID указываются через запятую.

## Основные команды

```text
/start - открыть меню
/collect 20 - собрать новые лиды
/collecttg 100 - собрать пачку лидов только с публичным Telegram-контактом
/next - следующий необработанный лид
/next 8 - следующий горячий лид с оценкой 8+
/top 10 - показать лучшие лиды
/search слово - найти проект
/count - статистика базы
/export - скачать CSV
/tglist 100 - скачать отдельный CSV с Telegram-контактами
/status - статус текущего сбора
/add Название | Сфера | @telegram | email | 8
/reset_review - сбросить отметки обработки
```

## Рабочий сценарий

1. Нажмите `Собрать 20 лидов`.
2. Откройте `Горячий 8+`.
3. Проверьте карточку проекта.
4. Нажмите `Открыть Telegram` и отправьте персональный оффер вручную.
5. Вернитесь в бота и нажмите `Взял в работу` или `Пропустить`.

## Развёртывание на BotHost

Добавьте переменные окружения из `.env.example` и укажите команду запуска:

```text
python main.py
```

Файлы `altyn_leads.csv` и `lead_state.json` создаются автоматически и не публикуются в Git.

При нескольких Telegram-контактах бот ставит выше партнёрство, коммерческий отдел, владельца или менеджера. Поддержка используется как запасной контакт, а новостные каналы, чаты и боты получают меньший приоритет.

## Логика отбора

Самые целевые лиды для франшизы:

- РФ/рублевые обменники с USDT, RUB, СБП, картами МИР или локальными контактами;
- OTC/P2P-команды, которые уже работают с USDT и фиатом;
- арбитражники, CPA/affiliate-команды, крипто-медиа и Telegram-каналы, у которых есть финансовый или крипто-трафик по РФ.

Платежные gateway, gift-card сервисы, крупные глобальные crypto infrastructure проекты и нерублевые локальные рынки не считаются горячими лидами. Бот может сохранить их как партнеров/инфраструктуру или лиды на потом, но ограничивает оценку, чтобы они не забивали очередь 8+.
